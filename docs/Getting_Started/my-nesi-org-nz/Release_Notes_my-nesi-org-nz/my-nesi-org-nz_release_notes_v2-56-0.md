## New and Improved

- Projects that have moved to [HPC Portal](https://hpc-portal.reannz.co.nz) now show a **Moved to HPC Portal** badge in your project list.
- Opening a moved project now shows a notice with a link to HPC Portal. Manage members, allocations and research outputs there. You can no longer change these projects in my.nesi.org.nz.
- The membership review prompt no longer appears for moved projects.
